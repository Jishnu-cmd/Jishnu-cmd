Python · FastAPI · React · TypeScript · Tailwind CSS · OWL Ontology

Developed a FastAPI backend with JWT role-based access, SLA

02. Gesture-Controlled Games
Python · OpenCV · MediaPipe
Built webcam-based hand-gesture controllers for Hill Climb Racing
and Subway Surfers.
Used MediaPipe hand landmarks tracked through OpenCV.
Translated recognised gestures into real-time simulated keyboard
input.
03. Telecom Customer Churn Prediction System
Python · Scikit-learn · LightGBM · FastAPI · Streamlit · Docker
Tuned LightGBM on 7,043 records, achieving 0.861 ROC-AUC and
76.5% recall.

analysis.
Built a FastAPI and Streamlit application, packaged with Docker
Compose and pytest tests.
